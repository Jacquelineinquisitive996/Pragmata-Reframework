## 🔧 Troubleshooting

Sometimes software conflicts occur. Use these steps to solve common errors.

### The game crashes at launch
Conflicts between files often cause crashes. Delete the files you added to the game folder. Verify your game files through Steam. Reinstall the mod loader files carefully.

### D3D Device Removed error
This error often relates to graphics drivers. Update your NVIDIA or AMD drivers to the latest version. Disable any overclocking software running in the background. Lower your graphics settings inside the game menu if the error persists.

### Settings menu does not open
The mod loader uses a specific key to open its menu. Check the folder for a configuration file. Open this file with a text editor to see which key triggers the menu. Make sure the file named `DXGI.DLL` sits in the main game folder.

### Stuttering during gameplay
Stuttering happens if the game tries to process too many requests. Turn off vertical sync in the game menu. Use the built-in upscaling tools to lower the internal resolution. This reduces the load on your graphics card.
